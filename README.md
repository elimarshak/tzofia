# Tzofia (צופיה)

An open, non-commercial live map of air traffic, satellites and abnormal signals
(airspace closures, navigation interference, internet outages), starting with Israel.

Status: planning and design. No running code yet.

- `docs/plan-he.md` - the build plan (Hebrew)
- `docs/research/` - source research, 5 October 2026
- `design/mockup/` - first screen mockups

Aircraft data: adsb.lol (ODbL). Base map in mockups: Natural Earth.
